# Fleet Intelligence Copilot v0.1.0

Initial synthetic FDE capstone for fleet operations.

- Grounded vehicle explanations, contract expiry analytics, and deterministic maintenance anomalies.
- Versioned policy citations from a controlled local corpus.
- Support-case, escalation, and replacement-recommendation proposals with independent human approval.
- Expiry and evidence-digest checks; atomic, idempotent case execution and action audit.
- Request traces, latency/error/retry metrics, role controls, and score feedback.
- FastAPI Swagger interface, lightweight HTML dashboard, real local screenshots, and demo video.
- Pytest/Ruff checks, an independently authored evaluation suite, CI, Docker configuration, and FDE operations documentation.

Measured local results and limitations are in `docs/evaluation-report.md`. All data and tools are synthetic. No paid model API, live vehicle assignment, customer communications, or cloud deployment is included. CI and container results depend on the workflows running in this repository.
